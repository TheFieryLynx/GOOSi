# Материалы для подготовки к ГОСам. Бакалавриат ВМК МГУ, 3 поток

## Внимание
В связи с тем, что вопросы для разных кафедр могут быть различными, было принято решение создать отдельные ветки для таких кафедр.
Для билетов специфичных для кафедры АСВК перейдите в ветку `asvk`.

## Инструкции по компиляции
`run_*.sh` - скрипты для компиляции материалов.
`clean.sh` - скрипт для удаления всех временных файлов компиляции (`.aux`, `.log`, `.pdf` и т.п.).

Для компиляции исходников на Ubuntu нужны пакеты 
`texlive-science texlive-pstricks texlive-bibtex-extra biber`
(возможно неполный список)
